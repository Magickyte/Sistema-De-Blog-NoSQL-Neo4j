## Descripción del Proyecto
Sistema para la administración y publicaciones de un blog, con categorización, etiquetado y comentarios, ahora utilizando una base de datos de grafos (Neo4j) y utilizando el driver de neo4j en python para realizar las consultas dentro del programa, incluye un archivo de python "database.py" que contiene las instrucciones en cypher (son llamadas mediante funciones en python) para realizar las operaciones antes menciondadas.
